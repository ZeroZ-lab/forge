# Robot Simulation — Design System

> 科技实验室风格，暗色主题 + 青绿强调

## 产品气质

**关键词**: 科技感、精密、冷静、未来感

推导链: 机器人仿真 → 实验室监控界面 → 暗色背景 + 发光元素 → 科技感但不浮夸

## 颜色系统

### 背景层
| Token | 值 | 用途 |
|-------|-----|------|
| --bg-primary | #0a0e17 | 主背景 |
| --bg-secondary | #111827 | 控制面板背景 |
| --bg-tertiary | #1a2035 | 输入框/按钮背景 |

### 强调色
| Token | 值 | 用途 |
|-------|-----|------|
| --accent-primary | #00d4ff | 机器人、主操作 |
| --accent-success | #00ff88 | 运行状态、成功 |
| --accent-warning | #ffaa00 | 警告、暂停状态 |
| --accent-danger | #ff3366 | 碰撞、错误、停止 |

### 文字
| Token | 值 | 用途 |
|-------|-----|------|
| --text-primary | #e2e8f0 | 主文字 |
| --text-secondary | #94a3b8 | 次要文字 |
| --text-muted | #64748b | 禁用/提示文字 |

### 对比度: 所有文字/背景组合满足 WCAG 4.5:1 ✓

## 字体系统

| 用途 | 字体 | 大小 | 行高 |
|------|------|------|------|
| 数据/坐标 | JetBrains Mono, monospace | 12-14px | 1.5 |
| 标题 | Inter, system-ui | 16px | 1.4 |
| 按钮/标签 | Inter, system-ui | 13px | 1.0 |
| 状态栏 | JetBrains Mono, monospace | 11px | 1.0 |

## 间距系统

基准: 4px，常用层级: 4 / 8 / 12 / 16 / 24 / 32

## 设计令牌

| Token | 值 | 说明 |
|-------|-----|------|
| --radius-sm | 4px | 按钮、输入框 |
| --radius-md | 8px | 卡片、面板 |
| --shadow-glow | 0 0 8px var(--accent-primary) | 强调发光 |
| --shadow-panel | 0 0 20px rgba(0,0,0,0.5) | 面板阴影 |

## 组件样式

- **按钮**: 深色背景 + 青绿边框，hover 时发光。文字 Inter 13px
- **滑块**: 深色轨道 + 青绿填充，圆形拖动手柄
- **输入框**: --bg-tertiary 背景 + 1px 边框，聚焦时 --accent-primary 边框
- **信息卡**: --bg-tertiary 背景 + --radius-md，内边距 12px

## 反 AI 品味检查

- [x] 非默认蓝/灰：暗色主题 + 青绿强调，有辨识度
- [x] 有设计意图：实验室监控感，不是通用 dashboard
- [x] 网格覆盖层：增加科技感纹理
- [x] 按钮微发光：hover 时 --shadow-glow，有质感
- [x] 间距有节奏：4/8/12/16/24/32，非均匀 8px
