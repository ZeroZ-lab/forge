# Held-out task: small feature vertical slice

You are working in an existing task-management app. Add "archive completed
task" as a small user-facing feature.

Constraints:

- The user must be able to archive a completed task from the task detail view.
- Archived tasks must disappear from the active list.
- Do not add project-level documents unless the existing project rules require
  them.
- Provide the smallest meaningful verification command and output.

Review focus:

- Did the implementation close one user workflow end to end?
- Did the agent avoid splitting work into disconnected frontend/backend/data
  layers?
- Did docs remain proportional to the change?
