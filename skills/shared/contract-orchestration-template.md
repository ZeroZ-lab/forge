# contract-orchestration-template.md — 编排模板

> 供 feature contract.md 的 `## 编排` 使用。
> 记录胶水代码：入口、启动顺序、运行时调用链、事件绑定和冲突优先级。

---

## 编排

### 入口文件

`src/<entry-file>` — 唯一入口，负责初始化所有模块并启动主流程。

### 启动序列

```
1. <第一步>: <哪个模块的哪个函数>
2. <第二步>: <哪个模块的哪个函数>
   └── <子步骤>: <初始化时附带的创建>
3. ...
N. <最后一步>: 启动主循环 / 监听端口
```

### 主循环 / 请求处理

```
<每帧/每请求> 执行:
  │
  ├── <阶段 1>: <调用哪个模块的什么函数>
  ├── <阶段 2>: <调用哪个模块的什么函数>
  │   ├── for each <实体>:
  │   │   ├── <子步骤>
  │   │   └── <子步骤>
  │   └── <后处理>
  └── <阶段 N>: <输出/渲染>
```
