# Layout Patterns — 可组合布局模式

8 个布局模式，每个说明什么时候用、什么时候不用。布局服务于内容结构，不是装饰。

---

## 1. Hero + Cards

```
┌─────────────────────────────┐
│    Hero: 标题 + 副标题 + CTA │
├────────┬────────┬───────────┤
│ Card 1 │ Card 2 │ Card 3    │
└────────┴────────┴───────────┘
```

**适用**：2-4 个并列价值点、功能特性、服务类型
**不适用**：内容有严格顺序 · 超过 6 个并列项 · 需要深度阅读
**响应式**：桌面 3 列 → 平板 2 列 → 移动 1 列

## 2. Split Layout

```
┌──────────────┬──────────────┐
│   文字/说明   │   图/代码    │
└──────────────┴──────────────┘
```

**适用**：左右对比 · 文字配图解 · 问题→方案配对
**不适用**：内容超过 3 对 · 每侧信息量差异大 · 纯文本无视觉
**响应式**：桌面左右 → 移动上下堆叠

## 3. Bento Grid

```
┌────────┬────────┬───────────┐
│        │ Card 2 │           │
│ Card 1 ├────────┤  Card 4   │
│        │ Card 3 │           │
└────────┴────────┴───────────┘
```

**适用**：4-8 个独立但相关信息块 · 每块可独立理解 · 快速扫描
**不适用**：内容有严格序列 · 长文阅读为主 · 信息块少于 3 个
**响应式**：桌面不规则网格 → 平板 2 列 → 移动 1 列

## 4. Timeline

```
  ● Step 1 — 标题 + 描述
  │
  ● Step 2 — 标题 + 描述
  │
  ● Step 3 — 标题 + 描述
```

**适用**：时间序列流程 · 发展历程 · 操作步骤 · 版本变迁
**不适用**：并列无序列 · 超过 7 步（拆分） · 需要分支逻辑
**响应式**：桌面水平/垂直 → 移动垂直列表

## 5. Comparison Table

```
┌──────────┬────────┬────────┬────────┐
│  维度     │ 方案 A │ 方案 B │ 方案 C │
├──────────┼────────┼────────┼────────┤
│  价格     │  ✓     │  ✗     │  ✓     │
│  性能     │  ★★★   │  ★★    │  ★★★   │
└──────────┴────────┴────────┴────────┘
```

**适用**：多维度方案对比 · 功能矩阵 · 定价对比
**不适用**：少于 3 个维度 · 信息无法表格化 · 需要叙事
**响应式**：桌面完整 → 移动水平滚动或卡片化

## 6. Step-by-step Flow

```
┌─────────┐    ┌─────────┐    ┌─────────┐
│ Step 1  │ →  │ Step 2  │ →  │ Step 3  │
└─────────┘    └─────────┘    └─────────┘
```

**适用**：表单分步 · 教程/向导 · 配置流程
**不适用**：单步可完成 · 步骤间无依赖 · 需要自由跳转
**响应式**：桌面水平步骤 → 移动垂直步骤

## 7. Metric Grid + Table

```
┌────────┬────────┬────────┬────────┐
│ 指标 1 │ 指标 2 │ 指标 3 │ 指标 4 │
└────────┴────────┴────────┴────────┘
┌───────────────────────────────────┐
│            明细表格               │
└───────────────────────────────────┘
```

**适用**：Dashboard · 数据概览 · 监控面板
**不适用**：非数据密集 · 指标少于 2 个 · 无操作需求
**响应式**：桌面 4 列 → 平板 2 列 → 移动 1 列，表格水平滚动

## 8. Sidebar + Content

```
┌──────────┬────────────────────────┐
│  导航    │      主内容区          │
│  目录    │                        │
└──────────┴────────────────────────┘
```

**适用**：文档站 · 设置页面 · 有层级导航的内容
**不适用**：单页面 · 无层级结构 · 移动端优先
**响应式**：桌面固定侧栏 → 移动汉堡菜单 + 全宽

---

## 选择流程

页面类型（page-archetypes.md）→ 推荐布局 → 判断适用性 → 确定。一个页面可组合多个布局，但每个 Section 只用一个。
