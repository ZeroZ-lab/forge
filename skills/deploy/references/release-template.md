## 回滚方案

### 触发条件

- 错误率 > 1%
- P99 延迟 > 2s
- 健康检查连续失败 3 次
- 核心业务指标异常下降

### 回滚步骤

```bash
# 1. 回滚部署
# 2. 回滚数据库（如有迁移）
# 3. 验证回滚成功
# 4. 通知团队
```

### 回滚后

- [ ] 创建事故报告
- [ ] 分析根因
- [ ] 修复后重新走发布流程
