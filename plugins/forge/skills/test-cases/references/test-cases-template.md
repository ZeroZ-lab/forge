## 测试数据

### 数据构造

| 数据集 | 用途 | 构造方式 |
|--------|------|---------|
| validData | 正常路径测试 | 工厂函数 |
| invalidData | 边界测试 | 手动构造 |
| seedData | 集成测试 | 数据库 seed |

### 隔离策略

- 每个测试用独立 tenantId
- 测试数据库与开发库隔离
- 或使用事务回滚

### 清理策略

- 每个测试后清理创建的数据
- 或使用 beforeEach/afterEach 钩子

## 测试优先级

| 优先级 | 数量 | 说明 |
|--------|------|------|
| P0 | | 核心路径，必须通过 |

## 执行顺序

```
1. P0 正常路径（冒烟测试）
2. P0 边界 + 错误
3. P1 正常 + 边界
4. P2 全部
```

**并行策略**：P0 串行（确保基础可用），P1+ 并行

## 文件拆分（超 200 行时）

当测试用例数量导致文件超过 200 行时，按以下策略拆分：

```
testing/
├── test-cases.md          # 主文件：范围矩阵 + P0 用例（≤ 200 行）
└── test-cases/
    ├── p1-cases.md        # P1 用例
    ├── edge-errors.md     # 边界 + 错误用例
    └── data-strategy.md   # 测试数据构造/隔离/清理
```

主文件必须保留：版本信息 · 测试范围矩阵 · 测试优先级汇总 · 执行顺序
