# Goal drift red flag

Goal drift occurs when implementation diverges from the stated goal without explicit decision.

## Signals

- Adding features not in the goal
- Changing scope without updating goal.md
- Spending time on unrelated improvements
- "While I'm here, let me also..." syndrome

## What to do

1. Check: is this still within the stated goal?
2. If not, either update the goal or stop the drift
3. Record the decision in changelog
