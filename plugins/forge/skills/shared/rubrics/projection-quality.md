# Projection quality rubric

Use this rubric when checking code, frontend, tests, or release artifacts projected from documents.

| Dimension | Check |
|-----------|-------|
| Contract fidelity | Endpoints, fields, status codes, behavior, and constraints match documents. |
| Decision linkage | Key branches cite or clearly map to documented decisions. |
| Test evidence | Acceptance criteria have executable or inspectable checks. |
| Runtime safety | Errors, permissions, idempotency, concurrency, and rollback are handled where relevant. |
| No hidden decisions | Implementation does not add unrecorded product or architecture decisions. |
| Deviation handling | L0/L1/L2 or P0/P1/P2 findings are classified and routed. |
