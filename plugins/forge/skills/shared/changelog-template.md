# changelog-template.md — 迭代日志模板

> 每次迭代追加一条。最新的在最上面。
> 两种条目格式：首次创建（阶段产出）和迭代变更（决策修改）。

---

# Changelog — <Feature Name>

---

## 迭代变更条目

> 当已有 goal/modules 发生变更时使用此格式。

### v{版本} — {日期} — {变更标题}

- **决策变更**：FD#: 从 X 改为 Y（或：新增 FD#）
- **理由**：{为什么改}
- **影响范围**：{端点/组件/类型} — 纯追加 / 修改 / BREAKING
- **文件影响**：
  - src/routes/xxx.ts — 新增/修改
  - src/schemas/xxx.ts — 新增/修改
  - tests/xxx..test.ts — 新增/修改

---

## 首次创建条目

> 当某个阶段的产物首次生成时使用此格式。

### v{版本} — {日期} — {阶段名称}

- **触发**：{用户说的一句话 / 触发原因}
- **产出**：{文件列表，如 goal.md + 8 个 modules}
- **关键决策**：{FD# 摘要，如 FD1=Next.js, FD2=Zustand 双 store}

---

## v1.0 — {日期} — 初始版本

> 第一个条目，所有决策首次确定。

- **触发**：{项目启动 / 功能规划}
- **产出**：{全部文件列表}
- **关键决策**：{FD1-FDn 摘要}
