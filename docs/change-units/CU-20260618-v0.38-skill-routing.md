# CU-20260618-v0.38-skill-routing

## Type

- Methodology

## Intent

- Trigger: Forge 缺少用户可显式调用的最短链路 Router，也没有记录 Claude Code/Codex 调用策略差异。
- Goal: 增加只推荐不执行的 `guide`，并建立跨平台调用策略。
- Out of scope: 不把生命周期协议改成仅显式调用；不破坏自然语言默认主链。

## Decision

| # | 决策 | 选择 | 理由 | 拒绝 |
|---|------|------|------|------|
| 1 | Router | 新增显式 `guide` | 降低用户记忆成本且不扩大执行权限 | Router 自动执行完整链路 |
| 2 | Claude 调用策略 | `disable-model-invocation: true` | Claude 官方控制面 | 假设 Codex 消费该字段 |
| 3 | Codex 调用策略 | `agents/openai.yaml` policy | Codex 官方控制面 | 把产品特定字段混入通用 schema |
| 4 | 现有 lifecycle skill | 保留隐式触发 | Forge 默认使用自然语言路由 | 全部 orchestrator 改为 user-only |

## Behavior Change

- 用户可显式调用 `guide` 获得 L0–L3、调用深度、启用和跳过理由。
- `guide` 不调用其他 skill、不修改文件、不创建 Change Unit。
- `shared` 与 `guide` 在 Claude/Codex 两端均禁止隐式调用。

## Affected Surface

- `plugins/forge/skills/guide/`
- `plugins/forge/skills/shared/`
- `docs/skill-invocation-policy.md`
- Claude plugin manifest 与 marketplace
- `guide-shortest-chain` benchmark

## Risks

| Risk | Impact | Mitigation |
|------|--------|------------|
| 跨平台 metadata 不一致 | 高 | 分别使用官方字段，并由 Forge validator 校验 |
| Router 变成新编排器 | 中 | SKILL 明确只推荐；benchmark 禁止执行和产物 |
| 新 skill 增加发现成本 | 低 | 禁止隐式调用，description 保持单一职责 |

## Verification

- Codex manual：Agent Skills / `allow_implicit_invocation`
- Claude Code official skills docs：`disable-model-invocation`
- `node scripts/evaluate-skills.mjs`
- `guide-shortest-chain` 真实 Codex run

## Rollback

- 从 manifest 删除 `guide` 并删除其目录。
- 删除调用策略文档；现有 lifecycle routing 不受影响。

## Completion Evidence

- Static contract: `guide` 被 registry、manifest 和 benchmark 覆盖。
- Cross-platform evidence: Claude/Codex 官方文档确认使用不同调用策略字段。
- Runtime evidence: `.eval-runs/skills-suite/20260618-skill-upgrade-v039/` 中两个 Router case 均被 Codex usage limit 阻塞，尚未证明真实运行行为。
